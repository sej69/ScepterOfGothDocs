source/raw-floppies

This is a copy of the original C QNX 1.14 source code saved on 5-1/4" floppy disk images in QNX file system format (circa 1983-84).  I doubt anything can read the format today, but it should be possible for some kind soul to extract the code snippets from the 512-byte block images and stitch them together to recreate a facsimile of it (painstaking but do-able).

The QNX 1.14 version is the last and most feature-complete version. See Doug Wheeler's [History of Scepter](https://dwheeler.com/scepter-of-goth/scepter-of-goth.html) for details.
