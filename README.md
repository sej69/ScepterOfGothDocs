Official Documentation and History for Scepter of Goth

## Scepter of Goth

Alan Klietz created [The Scepter of Goth](https://massivelyop.com/2017/05/27/the-game-archaeologist-how-sceptre-of-goth-shaped-the-mmo-industry/) in 1978-79.  Scepter was the first multiplayer online roleplay game created in the United States. It was created independently of MUD1 in the UK.

Scepter became a [major historical influence](https://muds.fandom.com/wiki/Scepter_of_Goth) on MMPORG game design.

[Scepter History](https://dwheeler.com/scepter-of-goth/scepter-of-goth.html)

### Notes

- There are many fake reproductions of Scepter that have been posted to GitHub (see fakes).  This repo contains the only known source code for the actual Scepter game.

- The correct name is "Scepter of Goth", not "Sceptre of Goth"

- Scepter was renamed "Milieu" for a short time on the MECC Timeshare System before it was shut down. (Some histories incorrectly state that Milieu was a predecessor of Scepter.)

- Scepter was commercialized in 1983 by GamBit Multisystems.

- The sequel to Scepter was Screenplay (unfinished).
