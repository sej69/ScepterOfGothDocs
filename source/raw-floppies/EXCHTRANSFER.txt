Example /help/system/multi/hang_example
     This  procedure  is  called  when  a  user hangs up the
phone. You place any hangup processing you need here.
W
/*         do_hangup - Handle hangup processing.
           84/11/14.   A. B. Codesmith
*/
extern   unsigned int  All_mask;
extern   int           My_port;
do_hangup()
{
     extern int number_users;
     mwrite(All_mask, "### The guy on port %d just hung up!\n",
         My_port);
     number_users = number_users - 1;
     return;
}
     The mwrite() procedure will send text to all users 
with a matching bitmask.
          mwrite(mask, text)
              mask = unsigned bitmask.
              text = text to send.  Up to 256 characters.
                     Ending with a zero byte.
     The   mwrite()  procedure  handles  all  the  necessary
buffering  and  routing  to  get  the  text  to  the  user's
terminal.
     The logout() procedure will log the specified user
out of the program.
          logout(port)
               port = The port number of the user to be
                      logged out.  Usually My_port.
